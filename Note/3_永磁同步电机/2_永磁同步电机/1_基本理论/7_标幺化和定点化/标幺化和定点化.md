# Engine 标幺化和定点化

## 1. FOC的标幺化

相同的电机控制代码下，控制的电机可能各有不同，输入输出电压电流可能不同，控制参数也会发生对应的变化，为了在同一套代码框架下能够适应更多电机，可以使用标幺化，将物理量全部归一到[-1,1]的范围。
$$
x_{pu} = \frac{x_{real}}{x_{base}}
$$
 一般取基准值为能得到的最大值，此时$x_{pu}$在[-1,1]内。

- 基本基准值选取

  基准电压$U_b$：选择相电压最大值，该值取决于母线电压最大值$U_{dcmax}$：$U_b = \frac{U_{dcmax}}{\sqrt{3}}$；

  基准电流$I_b$：选择能采样到的最大电流；

  基准频率$f_b$：选择最大电角频率；

- 其他基准值

  基准角频率$\omega_b$：$\omega_b = 2\pi f_b$；

  基准磁链/基准反电动势$\phi_b$：$\phi_b=L_bI_b = \frac{U_b}{\omega_b}$；

  基准阻抗$Z_b$：$Z_b = \frac{U_b}{I_b}$；

  基准电感$L_b$：$L_b = \frac{Z_b}{\omega_b}$；

  基准功率$S_b$：$S_b = U_bI_b$；

- dq轴系下的电压方程标幺化：
  $$
  u_d^{pu} = R^{pu}i_d^{pu}+\frac{L_d^{pu}}{\omega_b}\frac{d}{dt}i_d^{pu}-\omega^{pu}L_q^{pu}i_q^{pu} \\
  u_q^{pu} = R^{pu}i_q^{pu}+\frac{L_q^{pu}}{\omega_b}\frac{d}{dt}i_q^{pu}-\omega^{pu}L_d^{pu}i_d^{pu} + \omega^{pu}\lambda_{f}^{pu}
  $$

- PID 参数标幺化
  $$
  K_p^{pu} = K_p\frac{I_b}{U_b} \\
  K_i^{pu} = K_i\frac{I_b}{U_b} 
  $$

- SVPWM 标幺化

  基本电压矢量$\frac{2}{\sqrt{3}}$。

## 2. FOC定点化

对于没有 FPU 的 MCU ，直接使用浮点数运算是不合适的。这个时候应当使用定点数(见DSP)进行计算。

定点化的含义是：将一个小数乘以一个值($2^n$，此时用移位可以完成操作)，将小数转化为整数进行计算，运算后将该数得到的值除以$2^n$即可得到原来的小数。

FOC中，一般用IQ15格式(int32型整型数据)进行定点计算(15位小数精度)，实际上是乘以32768消去小数点转换为整型计算。

```c
#define   IQ15(A)         (int32_t)((A)*32768.0)
```

> 实际上这个转换过程仍然存在浮点数计算的隐患，如果使用 TI 提供的 `IQMath` 库可以避免此问题。

注意，该处使用32位数据存储，主要是由于非标幺化数据不在-1到1之间，需要有一定的存储范围。(标幺化后可以用Q格式定点计算)

- IQ15格式的加减法是平凡的。

- IQ15格式的乘法通过整型乘法实现，IQ格式必须格式相同才能实现乘法，IQ15和IQ15的乘法会得到IQ30的数据，需要右移15位得到IQ15数据。

  ```c
  #define   _IQmpy(A,B)    (int32_t)(((int64_t)(A)*(B))>>15)
  ```

  乘除2通过直接移位实现：

  ```c
  #define   _IQmpy2(A)     (int32_t)((A)<<1)
  #define   _IQdiv2(A)     (int32_t)((A)>>1)
  ```

- IQ15格式的除法通过以下方式实现：

  ```c
  static int32_t IQdiv(int32_t A, int32_t B) {
       // 安全处理除零
      if (B == 0) {
          return (A >= 0) ? INT32_MAX : INT32_MIN;
      }
  	
      // 左移15位被除数，IQ30/IQ15 -> IQ15
      int64_t temp = (int64_t)A << 15;
      
      // 舍入计算
      int64_t abs_B = (B > 0) ? B : -B;	
      int64_t half_B = abs_B / 2;				// 求一半绝对值
  
      // 在整数除法中，四舍五入可通过 被除数 ± 除数/2 实现，符号相同用加号，反之用减号
      if ((temp >= 0) == (B >= 0)) {
          temp += half_B;
      } else {
          temp -= half_B;
      }
  	
      // 除法执行
      int64_t result = temp / B;
      return (int32_t)result;
  }
  ```

- IQ15格式的开平方根通过实现：

  ```c
  // 用于计算32位无符号整数的平方根的整数部分
  static uint32_t IQsqrt(uint32_t n) {
      // 0平方根处理
      if (n == 0) return 0;
      
      // 巴比伦方法（牛顿迭代法的特例），通过迭代逼近平方根的值
      // y = 0.5 * (x + n/x) : x->y
      
      // 初始化猜测值
      uint32_t x = n;
      uint32_t y = (x + 1) >> 1;
      while (y < x) {		// 当 y 不再小于 x 时，说明已收敛
          x = y;			// 每次迭代将 x 和 n/x 的平均值作为新的猜测值
          y = (x + n / x) >> 1;
      }
      return x;			// x 是最终满足x*x ≤ n的最大整数
  }
  ```

- **FOC 非标幺定点实现(实际上只是浮点数计算转换为定点数计算，并没有进行标幺，主要考虑精度和数据范围问题)**

  - Clarke 变换

    ```c
    Ialpha = Ia;
    Ibeta = _IQmpy((motorParams->Ib +_IQmpy2(motorParams->Ia)),18918);
    
    // 18918 = sqrt(3) * 32768;
    ```

  - Park 变换

    ```c
    Id = _IQmpy(Ialpha,cos_val) + _IQmpy(Ibeta,sin_val);
    Iq = _IQmpy(Ibeta,cos_val) - _IQmpy(Ialpha,sin_val);
    ```

  - SVPWM

    ```c
    // 过调制处理
    Valpha_sq = _IQmpy(Valpha, Valpha);
    Vbeta_sq  = _IQmpy(Vbeta, Vbeta);
    v_mag_square_x2_q15 = (uint32_t)Valpha_sq + (uint32_t)Vbeta_sq; // 求得电压矢量幅值
    v_max_square_x2_q15 = _IQ15(V_max); // 最大电压矢量幅值定点化
    
    if (v_mag_square_x2_q15 > v_max_square_x2_q15) {
        // 转换为 IQ30 格式后开平方根
    	uint32_t temp_for_sqrt = (v_mag_square_x2_q15 >> 1) << 15; 
    	int32_t mag_q15 = (int32_t)IQsqrt(temp_for_sqrt);

    		int32_t scale_factor = IQdiv(V_max, mag_q15);
    		Valpha = _IQmpy(Valpha, scale_factor);
    		Vbeta  = _IQmpy(Vbeta, scale_factor);
    	} else {
            Valpha = 0;
            Vbeta = 0;
        }

    // 最后使用扇区判断/谐波注入生成PWM占空比/ARR值
    ```

实际上，使用标幺化后的FOC，电流只需要根据ADC精度直接表示为整型(-2048-2048,Q12)，角度只需要根据编码器精度直接表示为整型(-32768-32768)，电压表示为整型(基准值为-32768-32768)。实际上，这只是进行增益计算，不影响系统性能。(此时已经退化为Q15表示，标幺值乘以32768计算)

**本质而言，定点化是所有数值乘以固定数值进行整型运算，运算结果除以该数值形成真实值；标幺化后，所有标幺值在-1到1内，定点化计算更加直观(32768就直接指代最大值，而非标幺条件下最大值是实际值直接乘以32768，不直观)。**

### 在 STM32 中导入 `IQMath` 库

TI 提供了 IQMath 库可以很方便的实现定点化操作，IQMath 库原来是在 TI 的 DSP 上使用的，不过也可以在 STM32 中导入该库。

IQMath 的 API 在其手册中已经详细介绍，导入时，首先根据 Cortex 型号找到对应的 `IQmathLib-cmx.lib`(实际上哪种型号都是通用的)。然后导入头文件`IQmathLib.h`即可使用。
